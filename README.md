# Sudoku AI Solver
**CSC202 Artificial Intelligence - CCP Project**

## Algorithms Implemented
1. Backtracking (Uninformed Search)
2. AC3 + MRV (Informed Search)
3. Forward Checking (Constraint Propagation)
4. Simulated Annealing (Local Search)

## How to Run
pip install matplotlib numpy
python main.py

## Features
- 4 difficulty levels: Easy, Medium, Hard, Expert
- Step-by-step animation
- Performance comparison dashboard
- Bar charts, radar chart, winner analysis
